# Asador Labella · Web

Web del Asador Labella (Pinos Genil, Granada): portada con la brasa en 3D que avanza con el scroll, vitrina, cochinillo, carta, el local y reservas por WhatsApp.

- Página: `index.html` (todo en un solo archivo) e imágenes/vídeos en `img/`.
- Ver en local: `python servidor.py` y abrir http://localhost:8765
